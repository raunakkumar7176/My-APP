#### Key Findings

1. **NEP textbook transition is confirmed:** Classes 6–8 use new titles (Ganita Prakash, Curiosity, Exploring Society, Poorvi, Malhar). Class 9 has new NEP textbooks for 2026-27 (Ganita Manjari, Kaveri). Class 10 remains on old textbooks until 2027-28. Classes 11–12 use old textbooks.

2. **Mathematics textbook naming convention:**
   - Classes 6–8: "Ganita Prakash" (two parts for Classes 7–8)
   - Class 9: "Ganita Manjari" (single book, 8 chapters)
   - Class 10: "Mathematics" (old, 14 chapters)
   - Class 11: "Mathematics" (14 chapters)
   - Class 12: "Mathematics" (13 chapters, two parts)

3. **Social Science structure varies by class:**
   - Classes 6–8: Integrated "Exploring Society: India and Beyond" (single textbook combining History, Geography, Civics, Economics)
   - Class 9: New NCF 2023 integrated structure — "Social Science Part 1" (9 themes) + "Social Science Part 2" (7 themes) = 16 themes. Replaces old separate History/Geography/Civics/Economics.
   - Class 10: Separate books (Contemporary India, Democratic Politics, India & Contemporary World II, Understanding Economic Development)
   - Class 11–12: Separate discipline-specific books per stream

4. **English textbook naming convention:**
   - Classes 6–8: "Poorvi" (5 units each)
   - Class 9: "Kaveri" (8 chapters)
   - Class 10: "First Flight" + "Footprints Without Feet" + "Words and Expressions 2"
   - Class 11: "Hornbill" + "Snapshots" + "Woven Words" (35 units)
   - Class 12: "Flamingo" + "Vistas" + "Kaleidoscope" (31 units)

5. **Class 9 Social Science completely restructured:** Under NCF 2023, the old standalone History/Geography/Civics/Economics chapters are replaced with integrated thematic units across two books. This is a fundamental structural change from previous years.

6. **Hindi verification gap:** Classes 6, 7, 10, 11, 12 Hindi not verified. Class 8 Malhar (8 chapters) confirmed but titles generic. Class 9 Hindi (4 books: Kshitij, Sparsh, Kritika, Sanchayan) — chapter count known (30) from Careers360 but titles not individually verified.
