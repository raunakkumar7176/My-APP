## 5. Validation Implemented

### Client-side Publish Readiness Checklist (Step 5 Review)
- Test title provided
- Duration set and valid (>0)
- Scoring configured (marks per question > 0)
- Test mode selected
- Group selected (when Group Test mode)
- Questions exist (≥ 1)
- At least one approved/valid question
- All questions valid (no invalid drafts)
- Syllabus references valid (always passes)
- Schedule valid (ends after starts)

### Client-side Publish Error List Dialog
When publish fails validation, shows a dialog with all failing items listed with error icons.
